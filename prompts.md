## Tips for Generating with Nano Banana 2

- Always specify `4K output`
- Add `hyper-detailed` and `rich textures` for maximum quality
- Use exact hex codes in prompts — Nano Banana 2 can interpret color references
- Add `cinematic depth of field` for professional look
- Specify `no text` and `no people` to avoid unwanted elements
- For 3D renders: add `photorealistic CGI render` or `ultra-detailed 3D visualization`
- For illustrations: add `flat isometric 2.5D illustration style`
- Export as WebP from generation tool before adding to project
- Target dimensions: 1200×800 for most sections, 1600×900 for hero, 800×800 for square cards
